# Pinterest Feeder

### Training Data 
Currently, I have it so you have to create an .env file and place the path in the variable `FILE_PATH`, but I may change this later. I have it this way mainly so users can use other folders that aren't in this project directory. 

### Running 
1. Create a virtual environment.
2. Run virtual environment and install all requirements
3. Create an .env file with the variable `FILE_PATH` which stores the directory with training data. You can either use the data given or use your own. 
4. Run `train.py` 
5. Run `test.py` with given or custom training data to test the model.
